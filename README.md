# 🐷 小猪电脑助手（helppiggyusePC）

给**电脑小白（学生）**用的卡通风 Windows 小助手，支持 Windows 10 / 11。

## 下载

👉 **[点这里下载最新版](https://github.com/baipiaodashi/helppiggyusePC/releases/latest)**

- 下载 `PiggyHelper-版本号.exe`，双击就能用，不需要安装
- 如果浏览器拦截 exe，就下载 `.zip`，解压后再双击
- 第一次运行如果 Windows 提示"已保护你的电脑"，点 **更多信息 → 仍要运行**（软件没有购买数字签名，不是病毒）

## 功能

| 功能 | 说明 |
| --- | --- |
| 🏠 首页 | 大白话搜索、8 个最常用功能、每日小技巧 |
| 🧭 功能导航 | 51 项：一点直达系统设置（音量、WiFi、蓝牙、字体大小……）、电脑自带工具、学习网站、常用软件官网、AI 助手 |
| 🧹 一键清理 | 8 个清理项目，每一项都用大白话写清楚"这是什么、删了会怎样"；另有"大文件整理"，找出微信/QQ/下载文件夹里的大文件，删除时先进回收站 |
| 🗺️ C 盘里有什么 | 把 C 盘分成 12 块（桌面、下载、软件、Windows 系统……），告诉你每块是什么、能不能自己删、该怎么删；只解释和打开文件夹，**不提供一键删除** |
| ⌨️ 快捷键指南 | 70 个常用快捷键，可搜索、分类；**按住 Ctrl / Alt / Win 一秒钟，屏幕下方自动弹出提示卡** |
| 💬 AI 问答 | 像聊天一样问电脑问题，支持 DeepSeek、通义千问、硅基流动、Kimi 或自定义接口（自己填 API Key）；AI 会推荐可以直接点开的功能 |
| ⚙️ 设置 | 提示卡开关、按住时长、开机自启、关闭时躲到托盘、AI 设置 |

## 隐私说明

- **按住提示卡**需要监听键盘，但小猪只判断"是不是一直按着 Ctrl/Alt/Win"，**不记录、不拦截、不上传任何按键**。个别安全软件可能会提示"键盘监控"，放行即可；不想用可以在设置里关掉。
- **API Key** 用 Windows 自带的加密方式只保存在你自己的电脑上（`%APPDATA%\PiggyHelper\settings.json`），不会上传到任何地方。
- 一键清理只删除清单里列出的缓存文件夹，聊天记录和你收到的文件不会被自动删除。

## 开发者说明

- 小猪形象是原创的，源文件在 `design/mascot/`（用 `gen.py` 生成 8 个动作）

- 技术：C# + WPF（.NET 8），单文件自包含 exe
- 代码在 `src/PiggyHelper/`
- 每次推送代码，GitHub Actions 会在 Windows 上打包 exe、启动软件并给每个页面自动截图（截图在 `ci-screenshots` 分支）
- 发布新版本：在 Actions 里手动运行"打包 exe"，填上版本号（如 `v1.0.0`）
