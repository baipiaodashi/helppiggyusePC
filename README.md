# 小猪电脑助手（helppiggyusePC）

一个给**电脑小白（学生）**用的卡通风 Windows 小助手，支持 Windows 10 / 11。

## 功能

| 功能 | 状态 |
| --- | --- |
| 卡通主页：最常用功能、每日小技巧、大白话搜索 | ✅ 已完成 |
| 功能导航：一点直达系统设置（音量、WiFi、蓝牙……）、电脑自带工具、学习网站、常用软件官网、AI 助手 | ✅ 已完成 |
| 一键清理：临时文件、浏览器缓存、微信/QQ 缓存；聊天文件单独列出由你决定 | 🚧 制作中 |
| 快捷键指南：快捷键大全 + 按住 Ctrl 弹出提示卡 | 🚧 制作中 |
| AI 问答：填入自己的 DeepSeek / 通义千问 API Key | 🚧 制作中 |

## 怎么下载使用

1. 打开本仓库的 **Actions** 页面，点最新一次绿色 ✅ 的运行记录
2. 在页面底部的 **Artifacts** 里下载 `PiggyHelper-exe`，解压得到 `PiggyHelper.exe`
3. 双击运行。第一次运行如果 Windows 提示"已保护你的电脑"，点 **更多信息 → 仍要运行** 即可（因为软件没有购买数字签名，不是病毒）

不需要安装 .NET，exe 是独立的，可以直接拷给同学用。

## 开发者说明

- 技术：C# + WPF（.NET 8）
- 代码在 `src/PiggyHelper/`
- 每次推送代码，GitHub Actions 会自动打包 exe，并在 Windows 上启动软件、自动截图检查界面
