# 🐷 小猪电脑助手（helppiggyusePC）

给**电脑小白（学生）**用的卡通风 Windows 小助手，支持 Windows 10 / 11。

## 下载

👉 **[点这里下载最新版](https://github.com/baipiaodashi/helppiggyusePC/releases/latest)**

- 下载 `PiggyHelper-版本号.exe`，双击就能用，不需要安装
- 如果浏览器拦截 exe，就下载 `.zip`，解压后再双击
- 第一次运行如果 Windows 提示"已保护你的电脑"，点 **更多信息 → 仍要运行**（软件没有购买数字签名，不是病毒）

| 功能 | 说明 |
| --- | --- |
| 🏠 首页 | 大白话搜索、四大本领、8 个最常用功能、每日小技巧 |
| 🧭 功能导航 | 51 项：一点直达系统设置（音量、WiFi、蓝牙、字体大小……）、电脑自带工具、学习网站、常用软件官网、AI 助手 |
| 🧹 一键清理 | 8 个清理项目，每一项都用大白话写清楚"这是什么、删了会怎样"；另有"大文件整理"，找出微信/QQ/下载文件夹里的大文件，删除时先进回收站 |

| ⌨️ 快捷键指南 | 70 个常用快捷键，可搜索、分类；**按住 Ctrl / Alt / Win 一秒钟，屏幕下方自动弹出提示卡** |

| ⚙️ 设置 | 提示卡开关、按住时长、开机自启、关闭时躲到托盘、剪贴板设置入口、AI 设置 |

## 隐私说明

- **按住提示卡**和**小猪剪贴板**需要监听键盘：提示卡只判断"是不是一直按着 Ctrl/Alt/Win"；剪贴板只拦下 Win+V，以及小窗口开着时的方向键、回车、Esc。其余按键原样交给系统，**不记录、不上传任何按键**。个别安全软件可能会提示"键盘监控"，放行即可；不想用可以在设置和"剪贴板"页里关掉。
- **小猪剪贴板**的记录只存在你自己的电脑上（`%LOCALAPPDATA%\PiggyHelper\Clipboard`），不会上传。密码管理器（KeePass、1Password、Bitwarden 等）标了"别记我"的内容不记；看起来像密码、密钥、身份证号、银行卡号的内容打码显示，并用 Windows 自带的加密方式保存（也可以设置成干脆不记）。
- **API Key** 用 Windows 自带的加密方式只保存在你自己的电脑上（`%APPDATA%\PiggyHelper\settings.json`），不会上传到任何地方。
- 一键清理只删除清单里列出的缓存文件夹，聊天记录和你收到的文件不会被自动删除。
- 高级模式的引擎拿不到你的 API Key 文件：Key 只在启动时通过环境变量交给引擎，不写进引擎的任何文件；引擎的遥测上报已关闭。

## 开发者说明

- 小猪形象是原创的，源文件在 `design/mascot/`（用 `gen.py` 生成 9 个动作）

- 技术：C# + WPF（.NET 8），单文件自包含 exe
- 代码在 `src/PiggyHelper/`
- 高级模式：`harness/` 里是引擎的依赖清单；对接代码在 `Services/Harness/`。卡片上的风险提示来自 `Services/CommandGuard.cs`（只提醒、不拦），测试在 `tests/PiggyHelper.Tests/`
- 小猪剪贴板：监听、存储、Win+V 在 `Services/Clips/`，小窗口在 `Windows/ClipboardPanel.xaml`，设置页在 `Pages/ClipboardPage.xaml`。界面参考了开源剪贴板工具 [EcoPaste](https://github.com/EcoPasteHub/EcoPaste)（只参考做法，代码是重新写的）
- CI 会真的往剪贴板里放文字、图片、文件，再模拟按 Win+V、方向键、回车，检查记录、粘贴、隐私跳过都对不对（`--clipboard-selftest`）
- CI 会用假的 AI 接口（`harness/selftest/fake_llm.py`）在 Windows 上把高级模式走一遍：普通命令直接执行、沙盒挡住工作文件夹外面、申请更大权限时同意才做
- 每次推送代码，GitHub Actions 会在 Windows 上打包 exe、启动软件并给每个页面自动截图（截图在 `ci-screenshots` 分支）
- 发布新版本：在 Actions 里手动运行"打包 exe"，填上版本号（如 `v1.0.0`）
